# 清理结果与白名单界面重构

## 主流程

双击 Killer 自动开始清理。完成后，主窗口显示「清理结果」，同一窗口提供「白名单」入口。切到白名单页编辑后，可以返回同一份清理结果。成功写入的规则从下一次清理开始参与判断。

当前结果页的白名单按钮会打开编辑窗，编辑窗再打开进程选择器。重构后，搜索、选择、规则详情、保存反馈和撤销均在白名单页内完成。现有独立命令行入口仍可打开对应的管理界面。

## 界面

| 页面 | 首屏信息 | 操作 |
| --- | --- | --- |
| 清理结果 | 清理摘要、失败状态、前后内存和进程列表 | 查看进程详情、重开应用、对刚关闭的应用点「下次保留」、进入白名单 |
| 白名单 | 搜索框、应用图标和名称、保留状态、行内「保留」 | 搜索运行中进程、添加规则、查看规则与撤销 |
| 同页详情 | 完整路径、PID 或实例数、命中规则与来源 | 查看或复制路径，选择需要的规则范围 |

借鉴 [Linear 首页](https://linear.app/homepage) 上的紧凑列表、清晰的选中状态与随选中项更新的详情区。窄窗口可将详情放到列表下方或行内展开。图标使用本地程序图标，提取失败时显示通用程序图标。搜索、滚动和键盘选择在图标加载期间应可用。

白名单页可查看已经保存的规则。系统保留规则只读。停止服务与优雅关闭仍由原有配置管理；在界面上保留独立、明确的用途标签。

## 保留范围

| 操作 | 匹配规则 |
| --- | --- |
| 点击一行的「保留」 | 默认按完整 exe 路径精确匹配。相同文件的所有实例均覆盖。 |
| 显式选「同名进程」 | 按 Windows 进程名匹配，范围可跨不同安装目录。 |
| 显式选「整个目录」 | 显示将保留的目录。该目录及其子目录中的 exe 命中，目录名相似的并列目录不命中。 |
| 无法读取路径 | 说明原因并提供显式的「按进程名保留」。 |

现有配置中的进程名规则和路径子串规则按原含义读取。新写入的精确文件规则与目录规则必须能和现有路径子串规则区分。列表、预演和正常清理使用同一套匹配语义。已保留的行显示实际命中的规则及来源。

## 保存和撤销

- 点击「保留」后直接写入。保存成功时刷新状态并提供「撤销」；写入失败时在原位置说明原因，保留用户当前的选择。
- 同一规则重复添加时保持一条。添加前后都依实际配置判断保留状态。
- 撤销仅移除该次成功新增的规则。仍有其他规则命中时，显示当前有效规则。外部并发修改后按最新配置处理，避免覆盖其他改动。
- 清理结果行使用完整 exe 路径添加规则，最近一次添加可就地撤销。行内保留操作与本次结束记录分别显示。
- 使用现有配置备份和原子替换能力。写入失败时，原配置仍可读取。

## 验收

- **入口与切换**\
  从正常模式的交互启动路径检查原有自动清理入口。用预演或合成结果验收「清理结果 → 白名单 → 清理结果」全程在一个窗口内，且结果摘要与列表可以找回。
- **查找与添加**\
  按进程名称或路径搜到目标，能看图标、完整路径和当前状态。单条规则通过一次「保留」操作保存成功。
- **范围与兼容**\
  用同名不同路径的 exe、安装目录内的多个 exe 与名字相近的并列目录验证三种范围；用现有配置验证传统的路径子串命中保持一致。
- **写入与撤销**\
  验证重启后规则仍在、重复点击只生成一条、配置写入失败时状态和提示正确，以及撤销后仍由其他规则保护的进程显示对应命中原因。使用临时配置模拟外部写入冲突。
- **界面与辅助操作**\
  用常规和最小窗口、100% 和 150% 缩放核对窗口布局、键盘可达性、长路径、路径不可读和图标缺失。按 [构建与验收](VERIFY.md) 使用离线回归、预演和合成界面完成验证。
